🍽️ Food Recipe App - Full Stack Project

📌 Project Overview

This project is a Full Stack Food Recipe Application developed using HTML, CSS, JavaScript, React, and MongoDB. The app allows users to browse, add, and manage recipes efficiently with an interactive and user-friendly interface.

🛠️ Features

📋 User Authentication: Secure login/signup using JWT authentication.

🍲 Add Recipes: Users can upload their own recipes with images.

🔍 Search & Filter: Find recipes based on ingredients, categories, or cuisine.

💾 Save Favorites: Users can save their favorite recipes for later access.

⭐ Ratings & Reviews: Users can rate and review recipes.

🌐 Responsive UI: Fully optimized for mobile and desktop.

🏗️ Tech Stack

Frontend: React, HTML, CSS, JavaScript

Backend: React. js

Database: MongoDB

Authentication: JWT-based authentication

🚀 Installation & Setup

Prerequisites

Node.js & npm/yarn

MongoDB (Local/Cloud - MongoDB Atlas)

VS Code or any Code Editor

Steps to Run

Clone the repository

git clone https://github.com/your-username/Food-Recipe-App.git
cd Food-Recipe-App

Install dependencies

cd client && npm install  # Install frontend dependencies
cd ../server && npm install  # Install backend dependencies

Run the backend server

cd server
npm start

Run the frontend app

cd client
npm start

Access the app
Open http://localhost:3000 in your browser.
